# Oldal1

A premium modern landing page built with Next.js and Tailwind CSS.

## Features

- Responsive design
- Premium UI styling
- Mobile-first layout
- Accessible navigation and typography
- Fast, production-ready Next.js setup

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Production build

```bash
npm run build
npm run start
```

## Tech stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS 3
